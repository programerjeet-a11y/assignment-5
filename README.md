# 🚀 Dev Stack

Dev Stack is a modern and responsive Technology Explorer website where developers can explore different technologies and build their ideal development stack.

## 🌐 Live Demo

🔗 [Live Demo](#)

## 📌 Project Overview

Dev Stack helps developers discover popular frontend, backend, database, programming language, styling, DevOps, and development tools.

Users can explore technology details, compare different options, and add their preferred technologies to a personal stack.

## 🛠️ Technologies Used

- React.js
- TypeScript
- Tailwind CSS
- DaisyUI
- React-Toastify
- JSON
- Vite
- React Icons

## ✨ Features

### 1. Explore Technologies

Users can view technology cards with:

- Technology icon
- Technology name
- Description
- Category
- Difficulty level
- Rating
- Popularity badge

### 2. Build Your Own Stack

Users can add technologies to the **Your Stack** section and create their own development stack.

- Add technology to stack
- Prevent duplicate technologies
- Remove individual technology
- Remove all selected technologies
- Display selected technology count

### 3. Responsive and Interactive UI

The website is fully responsive and works smoothly on:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

React Toastify is used to show success, warning, and information notifications.
